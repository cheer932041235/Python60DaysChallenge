# Python 分日学习与机器学习练习

按天组织的 Python、数据处理、机器学习和深度学习学习材料，包含 Jupyter Notebook、示例数据与配套代码。适合按主题自学、运行示例和修改实验。

## 如何使用

1. 根据下方索引选择主题，在本地 Jupyter Notebook 或 JupyterLab 中打开对应文件。
2. 从头阅读并依次运行单元格，按 Notebook 中的导入和数据路径准备环境。涉及 GPU 的例子可以在合适的计算环境中运行。
3. 尝试修改数据、参数或模型，并观察输出变化；遇到问题时，附上文件名、运行环境与报错信息提交 Issue。

仓库包含不同主题的独立练习，各 Notebook 的依赖与数据要求以文件内容为准。
